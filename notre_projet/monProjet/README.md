# monProjet — structure de départ MVC

Cette archive contient l’arborescence demandée. Les fichiers PHP sont des emplacements réservés, pas une application fonctionnelle.

- `public/index.php` : futur point d’entrée HTTP.
- `app/` : contrôleurs, modèles, vues et composants.
- `config/database.php` : emplacement de configuration de connexion (aucun mot de passe inclus).
- `app/Core/Database.php` : future classe de connexion PDO.
- L’identité de l’utilisateur sera conservée par une session PHP, indépendamment des connexions MySQL.

**Note :** `Product.php` et les noms de fichiers sont repris exactement du modèle fourni. On pourra adapter cela aux QCM.
